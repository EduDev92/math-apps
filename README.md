# Math App - מרחב לומדות אינטראקטיביות במתמטיקה

פלטפורמה עצמאית ללומדות אינטראקטיביות במתמטיקה המיועדת להפצה דרך GitHub Pages.

## מבנה הפרויקט

התוכן מאורגן לפי נושא, בתיקיות שטוחות תחת `topics/` - כל לומדה היא קובץ HTML עצמאי בשם הזהה למזהה שלה, בלי תיקיות-ביניים:

```
index.html                       # רכזת ראשית ויחידה - קישור לכל לומדה
exam.html                         # כניסה למבדק כיתתי עם קוד
shared/                          # נכסים משותפים: עיצוב (common.css),
                                  # bidi-utils.js, exams-config.js, score-tracker.js,
                                  # <step-progress>, <math-input-pad>
topics/<topic>/<id>.html         # לומדה בודדת, לדוגמה topics/line/line-01.html
```

כרגע קיימים:
- `topics/line/` - `line-01`..`line-12` (כיתה י', גיאומטריה אנליטית - הקו הישר)
- `topics/shapes/` - `shp-01`..`shp-05` (כיתה י', גיאומטריה אנליטית - צורות גיאומטריות; shp-03/shp-05 עדיין לא נבנו)
- `topics/exp/` - `exp-01`..`exp-09` (כיתה יב', שאלון 572 - הפונקציה המעריכית)

### הוספת לומדה חדשה
1. אם זה נושא קיים (למשל עוד לומדה בקו הישר) - להוסיף קובץ `topics/<topic>/<prefix>-NN.html` חדש ולהוסיף כרטיס ברכזת הראשית (`index.html`).
2. אם זה נושא חדש לגמרי - ליצור `topics/<topic-new>/` חדש עם מזהה קבוע (`<prefix>-01`, `<prefix>-02`, ...), ולהוסיף סקשן/כרטיס חדש ברכזת הראשית.

כל לומדה מתחברת לנכסים המשותפים דרך נתיב יחסי (`../../shared/...` מתוך `topics/<topic>/`), וכוללת קישור `.back-link` בחזרה לרכזת הראשית (`../../index.html`).

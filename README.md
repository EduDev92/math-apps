# Math App - מרחב לומדות אינטראקטיביות במתמטיקה

פלטפורמה עצמאית ללומדות אינטראקטיביות במתמטיקה המיועדת להפצה דרך GitHub Pages.

## מבנה הפרויקט

התוכן מאורגן לפי כיתה ואז לפי רמת יחידות לימוד:

```
index.html                       # רכזת ראשית - קישור לכל כיתה
shared/                          # נכסים משותפים: עיצוב (common.css),
                                  # <step-progress>, <math-input-pad>
gradeX/levelY/index.html         # פורטל הקורס של כיתה X ברמת Y יח"ל
gradeX/levelY/topics/NN-slug/    # לומדה בודדת בתוך אותו קורס
```

כרגע קיימים:
- `grade10/level4/` - כיתה י', 4 יח"ל (גיאומטריה)
- `grade12/level5/` - כיתה יב', 5 יח"ל (שאלון 572 - הפונקציה המעריכית)

### הוספת לומדה חדשה
1. אם הכיתה+הרמה כבר קיימות (למשל עוד לומדה בגיאומטריה) - להוסיף תיקייה תחת `gradeX/levelY/topics/` ולהוסיף כרטיס ב-`gradeX/levelY/index.html`.
2. אם זו רמה חדשה בכיתה קיימת (למשל 3 יח"ל בכיתה י') - ליצור `gradeX/levelNEW/` חדש עם פורטל משלו, ולהוסיף אותו לרכזת הראשית (`index.html`).
3. אם זו כיתה חדשה לגמרי - ליצור `gradeNEW/levelY/` ולהוסיף סקשן חדש ברכזת הראשית.

כל לומדה מתחברת לנכסים המשותפים דרך נתיב יחסי (`../../../../shared/...` מתוך `gradeX/levelY/topics/NN-slug/`), וכוללת קישור `.back-link` בחזרה לפורטל הקורס שלה (`../../index.html`), ופורטל הקורס כולל קישור חזרה לרכזת הראשית.

# Math App - מרחב לומדות אינטראקטיביות במתמטיקה (5 יח"ל)

פלטפורמה עצמאית ללומדות אינטראקטיביות במתמטיקה המיועדת להפצה דרך GitHub Pages.

## מבנה הפרויקט
- `index.html` - פורטל עץ הנושאים הראשי
- `shared/` - נכסים משותפים: עיצוב, מקלדת מתמטית עצמאית וסרגל שלבים
- `topics/` - יחידות הלימוד (לומדות עצמאיות)
